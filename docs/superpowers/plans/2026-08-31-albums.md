# Albums Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add first-class albums to Melody Music across D1, public API/UI, and admin UI.

**Architecture:** Extend the existing songs schema with a nullable album foreign key and introduce a dedicated albums table. Reuse existing Worker routing, R2 upload, Amplitude playback, and admin modal patterns.

**Tech Stack:** Cloudflare Workers, D1 SQLite, R2, vanilla ES modules, AmplitudeJS, Node test runner.

**Spec:** `docs/superpowers/specs/2026-08-31-albums-design.md`

## Global Constraints
- Preserve existing user login, favorites, playlists, history, and playback.
- Keep legacy `songs.album` text for backward compatibility.
- Public endpoints expose only published content.
- Reuse the existing R2 cover upload path.
